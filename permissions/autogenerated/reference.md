## Default Permission

Default permissions for tauri-plugin-nostr-sync

#### This default permission set includes the following:

- `allow-publish`
- `allow-fetch`
- `allow-sync-all`
- `allow-add-relay`
- `allow-remove-relay`
- `allow-get-relays`
- `allow-get-pubkey`
- `allow-get-status`
